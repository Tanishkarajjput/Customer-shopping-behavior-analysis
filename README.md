# 🛍️ Customer Shopping Behavior Analysis

An end-to-end **Customer Shopping Behavior Analysis** project built using **Python, SQL, and Power BI** to transform raw customer data into actionable business insights and an interactive dashboard.

---

## 📌 Project Overview

This project analyzes customer shopping behavior across demographics, products, purchasing patterns, subscriptions, discounts, shipping methods, payment methods, and customer loyalty.

The project follows a complete data analytics workflow:

**Data → Python → PostgreSQL → SQL Analysis → Power BI Dashboard → Business Insights**

The dataset contains **3,900 customer records and 18 attributes**, covering customer demographics, purchases, product categories, ratings, subscriptions, shipping, discounts, payment methods, and purchase frequency.

# 🐍 1. Data Analysis with Python

The raw dataset was loaded into Python using Pandas and analyzed in Jupyter Notebook.

### Data Exploration

The dataset contains customer-level information including:

* Customer ID
* Age
* Gender
* Item Purchased
* Category
* Purchase Amount
* Location
* Size
* Color
* Season
* Review Rating
* Subscription Status
* Shipping Type
* Discount Applied
* Promo Code Used
* Previous Purchases
* Payment Method
* Frequency of Purchases

The initial dataset contains **3,900 rows and 18 columns**.

### Data Cleaning

The analysis identified missing values in the `Review Rating` column.

A total of **37 review-rating values** were missing. These were handled by replacing missing ratings with the **median rating within the respective product category**.
Column names were also standardized to lowercase and converted to underscore-separated names for easier SQL/database usage.

### Feature Engineering

Two additional analytical features were created:

#### Age Group

Customers were divided into four age groups:

* Young Adult
* Adult
* Middle-aged
* Senior

This segmentation was created using quartile-based age grouping with `pandas.qcut()`.

#### Purchase Frequency in Days

Purchase-frequency categories were converted into numerical day values:

```text
Weekly          → 7 days
Fortnightly     → 14 days
Bi-Weekly       → 14 days
Monthly         → 30 days
Quarterly       → 90 days
Every 3 Months   → 90 days
Annually        → 365 days
```

This allows purchasing frequency to be analyzed quantitatively.

# 🗄️ 2. PostgreSQL Database

After preprocessing, the data was loaded into a PostgreSQL database for structured querying and business analysis.

## The Python workflow uses **SQLAlchemy and psycopg2** to connect Python with PostgreSQL and load the dataframe into the database.

# 🧮 3. SQL Business Analysis

Ten business questions were answered using PostgreSQL.

### Key analyses include:

**1. Revenue by Gender**

Compared total revenue generated by male and female customers.

**2. Discount & Spending Behavior**

Identified customers who used discounts but still spent at or above the average purchase amount.

**3. Top-Rated Products**

Identified the five products with the highest average review ratings.

**4. Shipping Analysis**

Compared average purchase amounts between Standard and Express shipping.

**5. Subscription Analysis**

Compared subscribers and non-subscribers based on:

* Customer count
* Average spend
* Total revenue

**6. Discount Rate by Product**

Identified the five products with the highest percentage of discounted purchases.

**7. Customer Segmentation**

Customers were categorized into:

```text
New        → 1 previous purchase
Returning  → 2–10 previous purchases
Loyal      → More than 10 previous purchases
```

**8. Product Performance by Category**

Identified the top three most-purchased products within each category using window functions.

**9. Repeat Buyers & Subscription**

Analyzed subscription status among customers with more than five previous purchases.

**10. Revenue by Age Group**

Compared revenue contribution across customer age groups.

The complete SQL queries are available in:

`customer_behavior_sql_queries.sql`

# 🚀 How to Reproduce the Project

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/customer-behavior-analysis.git

cd customer-behavior-analysis
```

## 2. Install Python Dependencies

```bash
pip install pandas sqlalchemy psycopg2-binary
```

## 3. Run the Jupyter Notebook

Launch Jupyter:

```bash
jupyter notebook
```

Open:

```text
customer_behavior_analysis.ipynb
```

Run the notebook sequentially to reproduce the data cleaning and feature-engineering workflow.

## 4. Set Up PostgreSQL

Create a PostgreSQL database and configure the connection details.

Load the processed customer data into PostgreSQL and execute:

```text
customer_behavior_sql_queries.sql
```

to reproduce the business analysis.

## 5. Open the Power BI Dashboard

Open:

```text
customer_behavior_dashboard.pbix
```

in Power BI Desktop.

Update the database/data-source connection if required and refresh the report.
